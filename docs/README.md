# Transit Intelligence GitHub Pages Build

This folder is generated by `node build-github-pages.js`.

It hosts the static front-end for GitHub Pages and points API calls to:

`https://emmanuel-transit-pulse.emmanuelkuh966.chatgpt.site`

GitHub Pages cannot run the Node API server or store private transit API keys. Keep realtime data on the Node/Sites API server and publish this folder as the Pages front-end.
